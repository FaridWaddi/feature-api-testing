Restful-Booker API Testing with Cypress

Project Overview

This project contains automated API tests created with Cypress for the Restful-Booker API.

The goal of this assignment was to practice API testing by sending requests to different endpoints and verifying:

API responses

HTTP status codes

Response body data

CRUD operations

Authentication required for protected endpoints

API under test: Restful-Booker
Base URL: https://restful-booker.herokuapp.com

3. Update Booking

Endpoint

PUT /booking/{id}

Example:

PUT /booking/1

Test File

updateBooking.spec.js

Purpose

Updates an existing booking.

The PUT request sends updated booking information and verifies that the API returns the updated data.

Authentication

The PUT endpoint requires an authentication token.

The test first obtains a token using:

POST /auth

The token is then sent in the request headers.

Example:

Cookie: token=<token>

Validations

The test checks:

HTTP status code

Updated first name

Updated last name

Updated total price

Updated deposit status

Updated booking dates

The response data is compared with the data sent in the PUT request.

4. Delete Booking

Endpoint

DELETE /booking/{id}

Example:

DELETE /booking/1

Test File

deleteBooking.spec.js

Purpose

Deletes an existing booking.

The DELETE endpoint also requires authentication.

Validations

The test verifies:

The DELETE request returns the expected status code.

The booking is no longer available after deletion.

A GET request can be used after DELETE to confirm that the booking cannot be retrieved.

Authentication

The Restful-Booker API provides an authentication endpoint:

POST /auth

The authentication request creates a token that can be used for protected operations such as:

PUT /booking/{id}
DELETE /booking/{id}

Example token response:

{
  "token": "example-token"
}

The actual token is generated by the API and should not be hard-coded in the test.

API Testing Approach

For each test, the following process was used:

1. Send the request

Cypress sends an HTTP request using:

cy.request()

2. Verify the status code

Example:

expect(response.status).to.eq(200)

3. Verify the response body

Example:

expect(response.body.firstname).to.eq("Mark")

4. Verify important fields

The tests validate the important data returned by the API instead of checking only the status code.
